# Local File Explorer

## 1. Project Overview

Local File Explorer is a read-only web application built using React. It allows users to select an actual folder from their local computer and browse its contents through an expandable folder hierarchy, similar to the VS Code Explorer panel.

The application does not use any preloaded or fake file data.

## 2. Technologies Used

- React
- JavaScript
- HTML and CSS
- File System Access API
- Playwright for automated testing
- Vite

## 3. Features

- Select a real local folder using the browser's folder picker.
- Display actual files and folders.
- Expand and collapse nested folders.
- Load folder contents when expanded (lazy loading).
- Display selected file and folder properties.
- Handle empty folders.
- Reset the previous folder when another folder is selected.
- Read-only access: no file modification or deletion.

## 4. Installation and Execution

### Prerequisites
- Node.js and npm
- Microsoft Edge or another supported browser

### Install dependencies

```bash
npm install
```

### Start the application

```bash
npm run dev
```

Open the localhost URL provided by Vite, usually:

http://localhost:5173

## 5. Browser Support

The application uses the File System Access API through `window.showDirectoryPicker()`.

- Microsoft Edge: Tested successfully.
- Google Chrome: Folder-picker issues were observed during testing and further compatibility verification is required.

The API requires a supported browser, a secure context (HTTPS or localhost), and explicit user permission.

## 6. Known Limitations

- Browser permission is required before accessing a local directory.
- The native folder picker must be operated by the user.
- Very large directories may take longer to load because directory entries are read asynchronously.

## 7. Testing

Manual testing covers real folder selection, nested folders, file properties, empty folders, cancellation, switching folders and large directories.

Automated testing uses Playwright with Microsoft Edge.

Run automated tests using:

```bash
npx playwright test --headed
```

## 8. Privacy and Security

The application accesses local folders only after explicit user selection and browser permission. It does not upload files to a server or modify local files.
