# Test Cases – Local File Explorer

## 1. Testing Environment

- Application: Local File Explorer
- Browser: Microsoft Edge
- Testing approach: Manual and automated testing
- Automation tool: Playwright

## 2. Manual Test Cases

The following test cases are designed to check the main features of the application.

| Test ID | Test Scenario | Test Steps | Expected Result |

| TC01 | Selecting a real folder | Click Open Folder and choose a folder from the computer | The selected folder and its actual contents should appear in the Explorer. |
| TC02 | Nested folder structure | Select a folder containing at least three levels of nested folders and expand them | All folders and files should appear in the correct hierarchy. |
| TC03 | Expand and collapse folders | Click a folder to expand it and click it again to collapse it | The folder contents should expand and collapse correctly. |
| TC04 | Checking file properties | Select a file from the Explorer | The properties panel should display the correct file name, relative path, size and last modified date. |
| TC05 | Handling empty folders | Select or expand an empty folder | An appropriate empty-folder message should appear without any errors. |
| TC06 | Cancelling folder selection | Click Open Folder and cancel the folder-selection dialog | The application should remain stable without unexpected errors. |
| TC07 | Switching between folders | Select one folder and then choose another folder | The previous folder contents and selection should be cleared and replaced with the new folder. |

## 3. Additional Performance Test

| Test ID | Test Scenario | Test Steps | Expected Result |
|---|---|---|---|
| TC08 | Handling large directories | Select a folder containing 500 or more files and folders | The application should remain reasonably responsive while displaying the folder contents. |

## 4. Automated Testing

Playwright is used to automate selected application behaviours.

- Testing framework: Playwright
- Browser: Microsoft Edge
- Test file: `tests/file-explorer.spec.js`

To run the automated tests, use:

```bash
npx playwright test --headed
```

The tests focus on checking application behaviour and verifying that the expected elements are displayed.
